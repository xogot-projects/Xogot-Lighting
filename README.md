# 3D Lighting (Xogot 3D Tutorial)

This project contains the example scenes used in the **Xogot 3D Modular Series - Introduction to Lighting** tutorial by **Erin Uptegrove**.

It demonstrates how to add and work with the core 3D light types in **Xogot** — the iPad and iPhone port of the Godot Engine — and explores the most important settings used to light 3D scenes effectively.

The project includes sample scenes for experimenting with **Directional**, **Omni**, and **Spot** lights, as well as shared lighting properties such as light energy, indirect lighting, shadows, and layer-based controls.

---

## Features

* Add and configure **DirectionalLight3D**, **OmniLight3D**, and **SpotLight3D**
* Use a **DirectionalLight3D** for sun and moon-style lighting
* Adjust **range**, **attenuation**, and **angles** for point and spot lights
* Experiment with core lighting properties such as **Energy** and **Indirect Energy**
* Explore basic **shadow behavior** and shadow tuning options
* Control which objects are affected by lights using **Cull Mask** and **Caster Layers**
